## Old-laptop compatibility — EXPERIMENTAL

One laptop had problems running lightweight Linux distributions. I researched older Linux/Ubuntu kernel versions and experimented with compatibility. The [troubleshooting notes](troubleshooting.md) still need the exact versions, symptoms, and final outcome.
