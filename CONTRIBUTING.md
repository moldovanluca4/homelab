# Contributing

I welcome technical corrections, questions, and notes from people working with similar hardware.

Open an issue or pull request with the relevant page, your suggested change, and a source or explanation where useful. For a new project idea, the [roadmap](docs/roadmap.md) is a good starting point.

## Editing the notes

- Use the [status labels](README.md) consistently and leave missing details as TBD.
- Keep observations separate from possible explanations and next steps.
- Use relative links and Mermaid blocks for diagrams.
- Update the service inventory, roadmap, and diagrams when a deployment changes.
- Follow the [publishing checklist](docs/publishing-checklist.md) before submitting files.

Contributions are covered by the [MIT License](LICENSE).
