# Contributing

I welcome technical corrections, questions, and experiences with similar hardware.

Open an issue or pull request with the relevant page, suggested change, and a source or explanation where useful. New project ideas belong on the [roadmap](docs/roadmap.md).

- Keep observations separate from hypotheses and future work.
- Use the [README's status terms](README.md); write “Not documented yet” for a missing factual detail when it matters.
- Use relative links and Mermaid blocks for diagrams.
- Update the inventory and diagrams when a deployment changes.
- Follow the [publishing checklist](docs/publishing-checklist.md) before submitting files.

Contributions are covered by the [MIT License](LICENSE).
